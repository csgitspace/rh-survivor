Emergency Controls

Use With Care

✦

These controls bypass the normal contest flow. Most are useful only in unusual circumstances — players quitting, ceremonies needing a re-run for testing, an entire tribe needing to dissolve. Read each tooltip before clicking.

Tribe Dissolve

Use when a tribe has dropped to ≤2 active members. Active members are redistributed across remaining tribes (smallest-first). The dissolved tribe stops competing.

Manual Eliminations

Force-eliminate a member outside of a tribal council vote. Useful only when someone quits or needs to be removed from the contest. The normal council flow handles routine eliminations — use Day Controls Step 4 for those.

Pick a tribe to see members.

MVP Voting Reset

Wipe all jury MVP votes and return MVP voting to "not started" state. Use only if the Friday reveal goes wrong and you need a do-over.

Ceremony Test Triggers

Manually fire a ceremony animation on the Contest dashboard. For testing the look and timing of ceremonies — useful when training a new admin or rehearsing the wrap party reveal.

Reset Progress

DESTRUCTIVE. Wipes all challenge results, eliminations, votes, locked competitors, and scores. Members and tribes are preserved. Use only to fully reset the contest after testing or to start a new run.
